2
Run Ingest Process (Preliminary)

Run the Chat AI Bot ingest pipeline to generate 05-event-product-mappings-latest.csv in alan-shared-resources/csv processed/. This file is required for Step 3 (Generate Schemas).

  • Open Chat AI Bot Ingest Pipeline
  • Upload CSV files from Step 1 (from alan-shared-resources/csv/)
  • Run Step 1: Import Metadata
  • Run Step 2: Ingest Content
  • Run Step 3: Build Mappings
  • Run Step 4: Finalize
  • Verify 05-event-product-mappings-latest.csv is saved to alan-shared-resources/csv processed/
Open Chat AI Bot Ingest Pipeline →
Note: This is a preliminary run. You'll run the ingest process again in Step 5 after schemas are deployed.
3
Generate Schemas
⚠️ Important: You need 05-event-product-mappings-latest.csv from Step 2. This file should be in alan-shared-resources/csv processed/.

Tab Order - Follow This Sequence:

1️⃣ Product Schema Tab (First - Generate Files)

  • Open Schema Tools (Product Schema tab is active by default)
  • Step 1: Upload raw-01-products-sqsp-export.csv from alan-shared-resources/csv/
  • Step 2: Runs automatically - generates 02 – products_cleaned.xlsx
  • Step 3a: (Optional) Fetch Google Reviews
  • Step 3b: Merge Reviews - generates 03 – combined_product_reviews.csv
  • Step 4: Generate Product Schema - creates schema files in outputs/schema/products/
Output Files: These files are required for Event Schema tab:
  • 02 – products_cleaned.xlsx (from Step 2)
  • 03 – combined_product_reviews.csv (from Step 3b)

2️⃣ Event Schema Tab (Second - Use Generated Files)

  • Switch to Event Schema tab (second tab at top)
  • Upload events_export.csv from Squarespace (from alan-shared-resources/csv/)
  • Upload 05-event-product-mappings-latest.csv from alan-shared-resources/csv processed/ (created in Step 2)
  • Upload generated files from Product Schema tab:
    • 02 – products_cleaned.xlsx (optional - for SKU values)
    • 03 – combined_product_reviews.csv (optional - for review enrichment)
  • Select category filter (Lessons or Workshops)
  • Click "Generate Event Schema"
  • Save outputs to alan-shared-resources/outputs/schema/
Open Schema Tools →
Note: After generating schemas, you'll run Step 5 (Final Ingest) for the complete data ingestion.
4
Deploy Schemas
  • Copy schema JSON files from outputs/schema/
  • Paste into alanranger-schema GitHub repo
  • Commit and push to GitHub
Schemas will be available at https://schema.alanranger.com/*.json for Squarespace.
5
Run Final Ingest to Chat AI Bot

After schemas are deployed, run the ingest process again to complete the data ingestion with all updated content and schemas.

  • Open Chat AI Bot Ingest Pipeline
  • Upload CSV files from Step 1 (from alan-shared-resources/csv/)
  • Run Step 1: Import Metadata
  • Run Step 2: Ingest Content
  • Run Step 3: Build Mappings
  • Run Step 4: Finalize
Open Chat AI Bot Ingest Pipeline →
